# Проект: Сайт-визитка для заказа наклеек (винил) с графиком работы

> Этот файл — память проекта. Читать в начале каждой новой сессии перед тем, как что-то делать в этой папке.

## Статус
Дизайн зафиксирован и одобрен пользователем. Код пока не писался. Следующий шаг — implementation plan (через writing-plans), затем разработка.

## Бренд

- **Название/домен: klebe.at** (от "kleben" — клеить; коротко, легко запомнить, не ограничивает будущее расширение услуг)
- **Визуальный стиль: индустриальный/мастеровой** — тёмный фон (графит/чёрный) + яркий акцент **оранжевый**. Отражает суть — реальное ремесло, реальный инструмент, а не абстрактная digital-услуга.

## Идея бизнеса

У владельца — плоттер (катер) для резки винила, трансферная бумага, навыки дизайна/вектографии. Целевая услуга: **профессиональные наклейки с графиком работы** для дверей/окон магазинов, баров, ресторанов — вместо рукописных бумажек или распечаток на принтере, которые сейчас массово используют такие заведения.

**Гео:** Вена, Австрия. В Вене — выезд мастера и монтаж на месте. За пределами Вены — готовая наклейка отправляется по почте, клиент клеит сам.

**Расширение услуг (не основной фокус сайта, но упоминается):** любые другие виды нарезки винила — рекламные вывески, наклейки на авто и т.д. На сайте — под отдельным простым блоком "нужно что-то другое — напишите/позвоните", без сложной формы.

**Модель продаж:**
- Пока без онлайн-оплаты. Клиент оставляет заказ → владелец получает уведомление в Telegram → сам звонит/пишет клиенту → договаривается → едет клеить сам или отправляет сотрудника, либо (если клиент не в Вене или согласен) отправляет наклейку по почте.
- Ориентировочная цена: от ~30€, с монтажом ~30-50€ (уточняется).
- Стратегия привлечения: сам ходит по городу, раздаёт визитки/оставляет в дверных щелях магазинов, которые видит без такой наклейки. Также планируется нанять человека для раздачи карточек по городу.

## Технический стек (решено)

- **Next.js** (React) + **Tailwind CSS**
- Деплой на **Vercel** (бесплатный тариф)
- **Без базы данных, без Stripe/оплаты на старте.** Форма заказа отправляет данные через маленькую serverless-функцию (API route) в **Telegram-бота** владельца (создаётся бесплатно через @BotFather) — прилетает сообщение с именем, телефоном, выбранными параметрами.
- **Framer Motion** для анимаций (плавное появление блоков при скролле, hover-эффекты, анимация шагов формы) — легковесно, не вредит скорости загрузки.
- Два языка на старте: **немецкий (основной) + английский**, архитектура готова для добавления третьего языка позже (актуально для Вены — много не немецкоязычных жителей).

## Структура сайта (одностраничник)

1. **Hero** — крупный заголовок, фото примера наклейки, кнопка "Заказать", fade-in анимация
2. **Как это работает** — 3 шага с иконками (Выбери → Отправь → Приклеят/пришлют)
3. **Примеры работ** — галерея фото (двери, окна, машины)
4. **Цены** — простая таблица (качество плёнки × размер → цена)
5. **Форма заказа** (см. ниже)
6. **Зона доставки** — блок "Вена — приедем и приклеим" / "Другой город — почта, клеишь сам"
7. **Контакты/футер**

## Форма заказа (решено — максимально простая)

Два пути на выбор клиента:
- **A) Заполнить самому** — быстрая конфигурация в 2 клика + текст графика
- **B) "Просто оставить контакты"** — только имя + телефон, без деталей (для тех, кто не может/не хочет разбираться в цифровых формах или не владеет языком) — дальше созванивается и уточняет всё сам владелец

### Путь A — поля (только клики, минимум набора текста):
1. **Качество плёнки** — 3 варианта (дёшево/3 года, стандарт/5 лет, премиум/8-10 лет)
2. **Цвет** — 2-4 варианта (белый, чёрный, возможно золотой/серебряный)
3. **Размер** — 2-3 варианта (например 25×25, 30×30, 35×35)
4. **График работы** — умный конструктор вместо свободного текста:
   - Переключатель "Одинаковые часы каждый день" (по умолчанию вкл.) → один интервал времени (выпадающие списки, шаг 30 мин)
   - Если выключить — разворачиваются 7 строк Пн-Вс, каждая со своим "открыто/закрыто" + часами
   - Необязательное короткое доп. поле текста (сайт, слоган и т.п.)
5. **Имя**
6. **Телефон**

Вопрос "с какой стороны стекла клеить (внутри/снаружи)" **сознательно убран из формы** — уточняется по телефону, не должен тормозить заполнение.

Количество (обычно 1-2 шт) — не блокирующий вопрос, можно уточнить при звонке, не обязательно поле в форме.

## Маркетинг / Флаер-визитка (обсуждено, макет — отдельная задача после сайта)

- Формат: **визитка 85×55мм**, не флаер А4 (дешевле, не воспринимается как мусорная реклама, охотнее оставляют "на потом")
- Лицо: приём **"до/после"** — фото рукописной бумажки рядом с профессиональной наклейкой + заголовок-боль ("Ваш график работы выглядит непрофессионально?")
- Оборот: крупный QR-код + короткий домен вручную + цена крупно ("от 30€, готово за 2 дня") + телефон/Telegram для прямого контакта
- **Важно:** зашить в QR-код метку источника (например `сайт.at/?from=karte`) — чтобы отличать в аналитике заказы от карточек от заказов "вживую"

## SEO / Обнаружение в интернете

- Технически покрывается стеком (Next.js быстрый, правильные мета-теги/структура)
- Ключевые слова на немецком: Öffnungszeiten Aufkleber, Schaufensterbeschriftung, Folienbeschriftung Wien и т.п.
- **Google Business Profile — важнее самого сайта на старте** для локальных запросов (Google Maps часто показывается раньше органической выдачи)
- Ниша узкая → мало конкурентов, целящихся именно в этот запрос → реальный шанс быстро попасть в топ

## Google Business Profile — план (владелец работает из дома, без магазина)

- Использовать тип **"выездной бизнес" (Service Area Business)**
- При настройке: "Я доставляю товары/услуги клиентам" + "Скрыть мой адрес"
- Домашний адрес не показывается публично, используется только для верификации Google (обычно открытка по почте)
- Указывается **зона обслуживания** (Wien целиком или конкретные районы), а не адрес — видимость в поиске не зависит от того, сколько людей живёт рядом с домом владельца
- Категория бизнеса — подобрать точный немецкий термин (Schilderhersteller/Beschriftungen или близкое)

## Деплой (Vercel)

1. Запушить репозиторий на GitHub (это делает разработчик — тебе не нужно самому разбираться с git/GitHub).
2. Импортировать проект в Vercel (vercel.com → New Project → выбрать репозиторий).
3. В настройках проекта Vercel → Environment Variables добавить `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (те же значения, что в `.env.local`). Что это за значения и как их получить — см. `.env.local.example` в корне репозитория.
4. Deploy. Позже подключить домен klebe.at в Vercel → Settings → Domains.
